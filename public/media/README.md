# LetssAI Service Image Pack

This pack contains 35 transparent service visuals in two formats:

- `PNG`: high-quality master asset
- `WebP`: optimized website asset

The images use LetssAI's emerald green, dark green, white, and silver visual language. Use the WebP version on production pages and retain the PNG version as the editable/master source.

## Website implementation notes

- Prefer WebP in the page markup and keep PNG as the fallback or source master.
- Preserve transparency; do not add a white background during optimization.
- Keep the image aspect ratio unchanged and use `object-fit: contain`.
- Use the supplied alt text when the image communicates meaning. Use an empty alt attribute only when an image is purely decorative.
- Confirm visual contrast on both light and dark page sections before publishing.
